# 播客后期分发助手 · 产品定义 v0.2

## 一句话定位（v1.1 润色）

**剪完之后，交给我们。** 除剪辑外，为播客的制作与宣传全程保驾护航：发布物料一次备齐，AI 找准每期的宣传爆点、快速产出爆款笔记与切片，并随使用不断沉淀你的节目风格——越用越懂你，判断越来越准，还能反哺下期录制灵感。

分版本表述：MVP 兑现「省」与「准」（物料自动化 + 爆点识别）；「懂你」（风格记忆）V2 起兑现；「灵感」（选题反哺）V2 的选题雷达兑现。对外文案只承诺当前版本已有的能力。

## 核心价值

**核心洞察**：对独立播客主来说，创作的乐趣在「聊」，痛苦在「发」。录音结束只完成了 50% 的工作，剩下的转写、整理、起标题、写简介、做宣传是纯消耗性劳动，且直接决定播放量（标题和 shownotes 是小宇宙的分发抓手）。

**价值主张（三层，v1.1）**：
1. **省**：剪完到发布/宣传之间的所有手动操作（转写、章节、标题、封面、shownotes、卡片、切片、笔记）一次备齐，从 1-3 小时压到 ≤20 分钟
2. **准**：不是机械摘要，而是替你判断「这期的宣传爆点在哪」——选出最可能出圈的片段和角度，产出对味的爆款笔记/切片
3. **懂你**：越用越了解你的节目风格（标题调性、听众画像、哪类内容数据好），判断越来越准，并反哺下期录制灵感（V2 选题雷达）

**边界（v0.2 修订）**：做基于文字稿的 AI 剪辑建议与一键成片；不做多轨编辑、BGM/混音、降噪（引导用户先用 Adobe Podcast Enhance 免费处理）、不做录音。详见《04-工作台详设》。

**为什么用户选我们而不是直接用 ChatGPT**：
1. 免去「转写 → 喂给 AI → 反复调 prompt → 拼装格式」的流水线，一步到位
2. 输出格式原生适配小宇宙 + 小红书生态（章节时间戳、金句卡片尺寸、笔记风格），通用 AI 给不了
3. 记住你的节目风格（往期标题风格、固定栏目结构），越用越像你

## 目标人群

**主人群：中文独立播客主（1-3 人档，无制作团队）**
- 在小宇宙发布为主，用爱发电或半商业化
- 每期后期整理花 1-3 小时，是弃更的主要原因之一
- 愿意为省时间付小钱（参照：剪映会员、Notion 定价心智）
- 数量参考：小宇宙活跃节目数万级，长尾极长

**暂不服务**：
- 商业播客团队（有专职后期，需要的是协作流程而非单点工具）
- 纯听众（BibiGPT 等已占位）
- 视频播客（链路不同，先不碰）

## User Stories

按一期节目的生命周期排列，⭐ = MVP 必须。

**剪辑（raw 素材 → 成品，v0.2 新增，【已拍板 2026-07-16：不进 MVP，排 V1.5】）**
0. 作为播客主，我想上传原始录音后，AI 标出该删的填充词、口误、冗余和跑题段落，我在文字稿上逐条采纳、按选定的节目风格（紧凑干货/松弛闲聊/叙事精编）出成品，这样我不用在剪辑软件里反复听着找。

**发布前（核心链路）**
1. ⭐ 作为播客主，我想上传音频后自动得到带说话人区分的逐字稿，这样我不用手动听打或买转写工具再手动整理。
2. ⭐ 作为播客主，我想自动生成带时间戳的章节列表，这样听众能跳转，小宇宙页面也更专业。
3. ⭐ 作为播客主，我想得到 3-5 个不同风格的标题备选（悬念型/干货型/情绪型），这样我不用对着空白框纠结半小时。
4. ⭐ 作为播客主，我想一键生成结构完整的 shownotes（本期简介、章节、提及的书/链接、嘉宾介绍），格式直接符合小宇宙习惯，复制即发。
4b. ⭐ 作为播客主，我想每期自动生成延续节目主视觉的单集封面图（自动排入标题、期数、嘉宾名），这样发布时不用再开设计工具，专辑页还保持统一风格。

**发布后（增长链路）**
5. ⭐ 作为播客主，我想从本期内容自动提取 3-5 条金句，生成可发小红书/朋友圈的引用卡片，这样每期都有宣传物料而不是发完就沉。
6. ⭐ 作为播客主，我想让 AI 找出本期最出彩的 1-3 个片段（有观点冲突、金句、情绪高点的 30-90 秒），直接给我切好的音频切片 + 推荐文案，这样我不用重听一遍全集找亮点。
7. 作为播客主，我想把切片一键做成带字幕和波形动画的竖版视频（audiogram），直接发小红书/视频号，让音频内容能在图文/视频平台被"看见"。
8. 作为播客主，我想生成一篇小红书风格的宣传笔记（标题+正文+话题标签），把播客流量从图文平台引过来。

**长期（留存钩子，V2）**
9. 作为播客主，我想让工具记住我的节目名、固定栏目、往期标题风格，产出越来越贴合我的调性。
10. 作为播客主，我想看到往期数据的复盘（哪类标题/选题播放好），辅助下一期选题。

> 切片能力的实现分层：Story 6（AI 选段 + 切音频 + 配文案）技术上是「转写时间戳 + LLM 选段 + ffmpeg 切割」，MVP 可做；Story 7（audiogram 视频渲染）工作量明显更大，放 V1.5，MVP 先交付音频切片让用户自己配图发布。

## 成功指标（MVP 阶段）

- 北极星：每周有 ≥1 期真实节目用它完成发布（先从你自己的播客开始）
- 质量指标：生成物料「不改直接用」的比例
- 简历指标：3-5 个外部真实用户 + 使用反馈迭代记录
