## 1. 目标与成功标准

- 用户价值：把一期节目的发布准备从 1-3 小时压缩到 ≤20 分钟
- 北极星：每周 ≥1 期真实节目经它完成发布
- 质量标准：物料「不改直接用」率（自评+试用用户访谈），目标 ≥50%
- 验证目标：上线 2 周内 3-5 个外部播客主完整走通一期

## 2. MVP 范围

**In**：邮箱账号体系｜文件上传+链接解析｜Fun-ASR 转写（说话人分离）｜标题×5｜单集封面图（模板渲染）｜shownotes｜章节｜金句卡片｜出彩切片｜小红书笔记｜发布台校对（编辑/重roll/复制发布包）｜历史｜节目设置（主视觉/固定尾部）｜额度 4 期/月｜邮件通知

**Out（版本路线）**：剪辑台四层建议与成片（V1.5）｜audiogram 视频（V1.5）｜AI 生图封面背景（V1.5）｜手机号+短信（V1.1）｜风格记忆与数据复盘（V2）｜选题雷达（V2）｜任何平台 API 对接（远期）

## 3. 信息架构与全局导航

```
未登录：落地页 ─ demo 物料包（只读） ─ 注册/登录弹窗
登录后（顶栏常驻：Logo｜我的节目｜+ 新建一期｜额度徽标｜设置｜头像）
 ├─ 历史页（登录后默认页；空状态引导新建）
 ├─ 新建一期：上传页 → 处理中页 → 发布台
 └─ 设置：节目信息 / 主视觉 / 固定尾部 / 账号
```

路由约定：/ 落地｜/episodes 历史｜/new 上传｜/e/{id} 处理中与发布台同路由按状态渲染｜/settings

## 4. 页面详设

### P0 落地页

- 首屏：主标题「剪完之后，交给我们」+ 副标题「10 分钟备齐全套发布物料，AI 帮你找准这期的宣传爆点，产出能出圈的笔记和切片」+ 主 CTA「免费开始」+ 次 CTA「看看示例」（文案只承诺 MVP 已有能力；「越用越懂你的节目」「录制灵感」等愿景放品牌故事区，见 01 v1.1 定位）
- 示例区：内嵌一期 demo 节目的完整物料包（只读发布台，可切 Tab），让用户 30 秒看懂产品交付什么
- 三步说明：上传 → AI 生成 → 复制发布
- 底部：定价说明（现阶段免费 4 期/月）
- 交互：点「免费开始」弹注册；demo 区任意「复制」按钮点击也弹注册（转化钩子）

### P1 注册/登录（弹窗，非独立页）

- 邮箱输入 → 发送 6 位验证码 → 输码即注册并登录（无密码）
- 文案：错误态「验证码不对，再试试」；60s 重发倒计时
- 预留：UI 上不出现手机号；数据层 users.phone 预留（V1.1）
- 注册成功 → 若从落地页来 → 直接进上传页（减少一跳）

### P1.5 首次建节目（onboarding，注册后仅一次）

- 单屏表单：节目名（必填，唯一一个必填项）+ 常驻说话人（选填，默认 1 行填自己）+「主视觉稍后再设」
- 完成 → 直接进上传页。之后节目信息全部走设置页，上传页不再重复填
- 多节目支持：MVP 一个账号一档节目；「+新节目」入口置灰标注 V2（数据模型已按 users→shows 1:N 设计，不返工）

### P2 上传页（v1.1 重设：每期只问一个问题）

布局：左 60% 上传区，右 40% 本期信息卡。

**上传区**
- 拖拽/点选文件：mp3/m4a/wav/aac，**≤2h**（受说话人分离限制，见 12 文档 ★1）且 ≤500MB；前端选中即校验，错误即时提示并给出压缩建议（推荐工具+一行 ffmpeg 命令）
- 上传后服务端自动转**单声道**再送 ASR（说话人分离仅支持单声道）；原始音频原样保留供用户下载
- 或粘贴链接：RSS / 小宇宙单集 URL；解析成功显示「已识别：{标题}·{时长}」；失败提示降级上传文件
- 进度条：分片上传+断点续传；中断后重进页面可恢复，不重选文件

**本期信息卡（设计原则：节目级信息绝不重复问）**
- 顶部只读条：「{节目名} · 第 {N} 期」+ 主视觉已设/未设状态 + 「修改」链接 → 设置页
- **核心字段（唯一主输入）**：「这期想宣传/传达什么？」多行选填，占位符示例："核心想推嘉宾『稳定是幻觉』的暴论；想吸引正在犹豫离职的听众"。此字段直接喂给标题/选段/宣传笔记的 prompt，是宣传精准度的最大杠杆，UI 上标注「填了会明显更准」
- 折叠区「更多设置 ▾」（默认收起）：本期嘉宾（名字+身份，用于嘉宾介绍与说话人标注；常驻说话人自动带入不用填）；生成项勾选（默认全选；链接导入且已有 shownotes 时默认只勾宣传三件套）
- 主按钮「开始生成」：上传完成前置灰，显示「上传完自动开始」开关（默认开）；额度不足时整页拦截（见 07 文档 C-9）

### P3 处理中页（/e/{id}，状态 < ready）

- 阶段条：上传 ✓ → 转写中 → 生成物料中 → 完成；转写阶段显示动态预估（约为音频时长的 1/4，>2 分钟才显示预估）
- 转写完成：逐字稿立即可看可校对（说话人重命名此时即可做）
- 物料就绪一项亮一项（标题最先，切片最后），就绪即可点入查看——**不等全部完成**
- 顶部提示：「可以关掉页面，全部完成后邮件通知你」
- 失败态：见 §6 异常矩阵

### P4 发布台（核心页，/e/{id}，状态 ≥ ready）

**布局**：左 40% 逐字稿区；右 60% 物料区（7 Tab，默认落在标题 Tab，顶部 checklist 即总览）；顶部 checklist 条 + 「⋯」菜单（下载原始音频 / 导出逐字稿 txt·md / 删除本期）。

**物料统一契约（开发按统一组件实现，七个 Tab 不各写一套）**：编辑｜重roll（带一句话指令）｜版本回退（生成型物料保留 5 版；标题重生成 5 个时上一批整体存为一版）｜确认｜复制/下载｜失败单项重试｜「逐字稿已更新」刷新提示。封面图为配置型：无重roll/版本，但手改后有防覆盖提示（07-F3）。

**顶部 checklist**
- 7 个物料点：待处理（灰）/ 已确认（绿）；点物料 Tab 内「确认」变绿
- 全绿 →「复制发布包」按钮高亮；任何状态都可点，但未全绿时点它提示「还有 N 项未确认，仍要复制吗」
- 「复制发布包」内容：定稿标题 + shownotes 全文（含章节），小宇宙纯文本格式；旁边下拉可选 Markdown / HTML
- 「标记已发布」按钮：置灰直到复制过一次；点击后历史页状态变更

**逐字稿区**
- 按说话人分色（最多 6 色循环）；每段落显示时间戳；点击任意句子从该时间点播放（顶部悬浮迷你播放器：播放/暂停/倍速 1x-2x/进度条）
- 说话人重命名：点说话人名 → 输入框 → 全局生效；「从此句起以下都是 X」批量改（处理串轨）
- 文本修正：双击句子进入编辑；修正后相关物料 Tab 出现「逐字稿已更新，建议刷新」小红点（不自动重跑）
- 划选任意文本 → 浮出「设为金句」按钮（送入金句 Tab 候选）
- 逐字稿导出：复制全文 / 下载 txt·markdown（发公众号与存档是高频需求）；srt 字幕 V1.5

**Tab 1 标题**
- 5 张候选卡：风格标签（悬念/干货/情绪/提问/金句引用）+ 标题文本 + 字数
- 卡片操作：点选=定稿（高亮）；编辑（就地改）；单卡重roll
- 底部指令重roll：输入框占位「例：更口语点 / 带上嘉宾名字 / 要有数字」+ 重新生成 5 个
- 定稿联动：自动写入封面图和宣传笔记（两处显示「已同步」toast）

**Tab 2 封面图**
- 首次进入且未设置主视觉 → 引导卡「先设置节目主视觉」→ 抽屉：上传 logo/底图、选主色（取色器+从底图自动提取 5 色）、字体风格（衬线/无衬线/手写体三选一）；保存为节目级设置
- 3 版式预览：大字标题版 / 嘉宾突出版 / 金句版；自动填定稿标题、期数（自动+1 可改）、嘉宾名
- 微调：字号 3 档、标题手动换行、底色/背景图替换（上传）
- 导出：3000×3000 PNG 下载；「确认」计入 checklist
- 主视觉在设置页更新后：本 Tab 显示「应用最新主视觉」按钮（历史期不自动追溯，07-K1）

**Tab 3 Shownotes**
- 分块卡片：本期简介 / 时间轴章节（引用 Tab4，此处只读）/ 提及清单 / 嘉宾介绍 / 固定尾部（节目级设置，此处可临时改）
- 每块：编辑 / 单块重roll（可带指令）/ 重roll 后保留上一版可回退（版本下拉，最多 5 版）
- 提及清单：每项「名称+类型（书/影/人/链接）+补充链接输入框+删除」；底部「+手动添加」
- 复制本 Tab / 计入发布包

**Tab 4 章节**
- 行式列表：`[mm:ss] 章节名`；点时间戳跳播试听该章节开头
- 操作：改名（就地）、合并（选相邻两行）、拆分（在逐字稿里定位点「在此拆分章节」）、拖拽微调时间（±30s 内，吸附句边界）
- 整体重roll（带指令，如"分粗一点/章节名更吸引人"），上一版进版本历史

**Tab 5 金句卡片**
- 候选列表：AI 5 条 + 用户划选加入的；每条显示原文+时间戳；「换一批」重roll AI 候选（用户划选的不受影响）
- 选中 ≤5 条 → 套主视觉模板（3 选 1）→ 预览网格 → 批量导出 PNG（1:1 和 3:4 各一套，zip 下载）

**Tab 6 切片**
- 候选卡 ×1-3：波形图（高亮选段）+ **结构化推荐标签**（如 `观点交锋` `情绪峰值` `语轮完整 92%` `含 2 处金句`，即 provenance）+ 一句话理由 + 时长 + 配套文案
- 选段算法（两级漏斗，详见 10 借鉴分析 ★1）：确定性信号预筛（说话人切换密度、笑声/感叹词、静音间隔、问答对结构、句长突变）产出 top15-20 候选 → LLM 精选排序并写理由。**禁止全稿直接喂 LLM 选段**
- 边界规则（★2）：起点吸附「说话人新一轮发言」，终点吸附「句末+短静音」；**问答必须成对**（不可只切答案）；`语轮完整度` 低于阈值的候选直接淘汰
- 微调：拖动起止把手，吸附**语轮边界**；试听；重选（丢弃此段，AI 补下一候选）
- 导出：单段 mp3 下载 + 文案复制
- 空态（AI 没找到高置信片段）：提示「本期未识别到高光片段，你可以在逐字稿划选一段生成切片」

**Tab 7 宣传笔记**
- 小红书格式预览：标题（≤20 字，emoji）+ 正文（钩子+3 看点+收听引导+@节目名）+ 话题标签行
- 整体重roll（带指令）+ 就地编辑 + 一键复制
- 引用联动：正文引用的金句/切片内容随源变更提示刷新

### P5 历史页

- 卡片列表：主视觉缩略 + 标题（未定稿显示文件名）+ 日期 + 时长 + 状态徽标（处理中/待校对/已发布/失败）
- 点击进入 /e/{id}；失败卡片显示原因+重试
- 空状态：插画 +「上传第一期，10 分钟后来拿物料」+ CTA
- 顶栏额度徽标：「本月剩 3/4 期」，hover 显示恢复日期

### P6 设置页

- 节目信息：节目名、简介、默认说话人
- 主视觉：同 P4 Tab2 的设置抽屉，此处可改
- 固定尾部：多行文本（订阅引导等，追加到每期 shownotes 末尾）
- 账号：邮箱、本月额度用量与恢复日期、退出登录、注销（连带删除音频与数据，二次确认）

## 5. 全局交互规范

- 所有生成中状态用骨架屏，不用转圈遮罩；生成类操作按钮 loading 态禁点
- 所有破坏性操作（删除物料版本、注销）二次确认；其余操作即时生效 + toast + 可撤销（5s）
- 复制成功统一 toast「已复制，去小宇宙粘贴吧」
- 桌面优先（≥1200px 双栏）；<900px 降级为单栏上下布局（逐字稿收起为抽屉）——移动端只保证可用，不做重点
- 快捷键（发布台）：空格播放/暂停，←→ 按句移动，Cmd+C 复制当前 Tab 内容

## 6. 异常矩阵（速查版；完整分岔审查见《07-链路闭环与异常策略.md》，共 12 条链路 50+ 分支）

| 场景 | 系统行为 | 用户出路 |
|------|----------|----------|
| 格式/大小/时长不合规 | 选中即拦截 | 提示上限+压缩建议 |
| 上传中断 | 断点续传自动恢复 | 手动重试不重选文件 |
| 链接解析失败 | 即时提示 | 降级上传文件 |
| 转写失败 | 自动重试 1 次 → 邮件+页面告知原因 | 重试按钮；不计额度 |
| 转写置信度低 | 顶部黄条提醒 | 建议先校对逐字稿再刷新物料 |
| 单项物料失败 | 该 Tab 显示失败卡 | 单项重试，不阻塞其他 |
| LLM 输出格式坏 | 服务端校验+自动重试 1 次 | 同上 |
| 说话人串轨 | — | 单句改 +「从此句起都是 X」 |
| 额度用尽 | 上传页拦截 | 显示恢复日期；（付费入口 V1.1 占位） |
| 会话过期 | 静默续期失败才弹登录 | 重新验证码，工作现场不丢 |

## 7. 数据模型（简）

- users（id, email, phone*, created_at）
- shows（id, user_id, name, intro, visual_config JSON, footer_text, default_speakers JSON）
- episodes（id, show_id, source_type[file/link], audio_url, duration, status, episode_no, transcript JSON[句级: text/speaker/start/end/confidence], created_at, published_at）
- materials（id, episode_id, type[title/cover/shownotes/chapters/quotes/clips/note], content JSON, version, confirmed_at）
- quota_ledger（user_id, month, used, limit=4）；转写/生成失败冲正
- 状态机：uploading → uploaded → transcribing → generating → ready → published；任一 *_failed 可重入

## 8. 埋点（核心事件）

注册成功｜上传开始/成功/失败（source_type, duration, size）｜转写完成（耗时, 置信度）｜物料生成完成（type, 耗时）｜物料编辑/重roll（type, 是否带指令）｜确认（type）｜复制发布包｜标记已发布｜checklist 全绿耗时（= 校对时长，核心体验指标）｜「不改直接用」代理指标：确认时 content 与初版 diff 为零的比例

## 9. 验收标准（对应 01 的 ⭐ story）

1. 90 分钟真实双人节目，从上传到全部物料就绪 ≤35 分钟，全程无人值守
2. 逐字稿说话人重命名一次全局生效；点句跳播误差 ≤1s
3. 章节时间戳落在真实话题边界 ±30s 内（人工抽检 10 处 ≥8 处达标）
4. 复制发布包粘贴到小宇宙后台后，格式无需二次调整
5. 封面图 3000×3000、每期视觉与主视觉设置一致；金句卡两尺寸导出成功
6. 切片起止在句边界、无爆音；下载 mp3 可直接发布
7. 异常矩阵 10 条逐条演练通过；额度扣减与失败冲正正确

## 10. 开放问题

1. demo 物料包用哪期节目？（建议用 Yi 自己节目的一期，最真实）
2. 期数自动+1 的起始值：首次让用户填当前期数
3. 品牌名/域名未定——影响落地页文案与邮件发件人
